\# Employee Onboarding Management System



\## Project Overview



The Employee Onboarding Management System is a Salesforce-based

application designed to manage employee information and automate

the onboarding process.



\## Technologies Used



\- Salesforce CRM

\- Custom Objects

\- Custom Fields

\- Record-Triggered Flows

\- Validation Rules

\- Reports

\- Dashboards

\- Git and GitHub



\## Features



1\. Employee Management

2\. Automated Onboarding Record Creation

3\. Document Submission Tracking

4\. Automatic Onboarding Status Update

5\. Joining Date Validation

6\. Employee Reports

7\. Onboarding Reports

8\. Employee Onboarding Dashboard



\## Custom Objects



\### Employee



Stores employee information such as:



\- Employee Name

\- Email

\- Phone

\- Department

\- Employment Type

\- Joining Date

\- Status



\### Onboarding



Stores onboarding information such as:



\- Employee

\- Start Date

\- Documents Submitted

\- Onboarding Status

\- Notes



\## Automation



\### Flow 1: Auto Create Onboarding



Automatically creates an Onboarding record when a new Employee

record is created.



\### Flow 2: Complete Onboarding



Updates Onboarding Status to Completed when Documents Submitted

is set to true.



\## Validation Rule



The Joining Date cannot be in the past.
